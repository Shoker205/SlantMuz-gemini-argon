# 🎧 SlantMuz

**SlantMuz** (от *SlantTech*) — современный мульти-источниковый музыкальный стриминговый хаб и аудиоплеер для Android в эстетике **Neon Aurora & Pastel Liquid Glass (Material Design 3)**. Слушайте полные треки онлайн из открытых каталогов, запускайте персональную алгоритмическую **«Мою волну»**, настраивайте свой **Музыкальный ДНК**, включайте мировые радиостанции и слушайте локальную коллекцию — без подписок, рекламы и ограничений.

---

## ✨ Главные возможности

### 🌊 Алгоритмическая «Моя волна» (`SlantWaveEngine`)
- **Многомерная персонализация**: динамический подбор потока музыки на основе выбранного **занятия** (*Просыпаюсь, В дороге, Работаю, Тренируюсь, Засыпаю*), **характера** (*Любимое, Незнакомое, Популярное*), **настроения** (*Бодрое, Весёлое, Спокойное, Грустное, Злое*) и **языка** (*Русский, Иностранный, Без слов*).
- **Граф похожих исполнителей (*Artist Similarity Graph*)**: коллаборативный поиск близких по звучанию и сцене артистов (через API связанных исполнителей и жанровые кластеры).
- **Волна по треку, автору или жанру**: запуск персональной радиоволны в одно касание от любой песни, карточки артиста или жанрового тега.

### 🧬 Музыкальный ДНК и настройка предпочтений
- **Мастер предварительной настройки вкусов**: выбор любимых жанров, языковых предпочтений, эпох релизов (*2020-е, 2010-е, 2000-е, Ретро*) и баланса открытий (*Родное и любимое / Сбалансированный микс / Радар открытий*).
- **Живой поиск авторов с обложками**: мгновенные подсказки автодополнения при вводе имени исполнителя с отображением круглых аватарок/обложек из глобальных каталогов.
- **Авто-адаптация под коллекцию**: рекомендации автоматически перестраиваются с учётом ваших лайкнутых треков, созданных плейлистов, сохранённых альбомов и истории прослушиваний.

### ⚡ Full-Track Upgrade и мгновенное воспроизведение
- **Защита от 30-секундных тизеров**: интеллектуальный резолвер `resolve://fulltrack/...` автоматически подменяет 30-секундные превью из каталогов метаданных (*Deezer / iTunes*) на полные аудиопотоки (*YouTube Music / Piped / Invidious, Audius, Jamendo*), сохраняя оригинальные обложки высокого разрешения и теги.
- **Переключение треков без задержек (*Zero-Lag Playback*)**:
  - Низколатентный буфер **Media3 / ExoPlayer** (старт воспроизведения от `550 мс`).
  - Параллельная гонка зеркал (`firstCompletedOrNull`) и кэш разрешённых URL (`0 мс` при повторном обращении).
  - **Фоновая предзагрузка (`Stream Prefetcher`)**: автоматическое разрешение и прогрев потоков для следующих 3 треков в очереди.

### 👤 Глубокие профили исполнителей и умная дедупликация
- **Полная дискография**: загрузка расширенного каталога артиста (50+ популярных треков и альбомов), карточки последнего релиза и биографии (*Wikipedia RU/EN*).
- **Изоляция источников**: треки одного исполнителя в его профиле аккуратно распределены по вкладкам конкретных платформ и не смешиваются между собой.
- **Умная очистка и алиасы (`TrackDeduplicationEngine`)**: распознавание кириллических и латинских алиасов (*Кино ↔ Kino, Скриптонит ↔ Scriptonite*), очистка мусорных тегов (`Official Video`, `HQ`) и фильтрация коротких сниппетов.

### 🎛️ Звук, Караоке, Коллекция и Виджеты
- **🎤 Синхронное караоке (LRC)**: живой текст песни (*LRCLIB*) с подсветкой активной строки и перемоткой по нажатию на любую фразу + режим **30-секундного трейлера (Highlight)** самой яркой части песни.
- **🎛️ 5-полосный DSP-эквалайзер**: аппаратные эффекты усиления баса (*BassBoost*), объёмного звука (*Virtualizer*), нормализации громкости (*Loudness Enhancer*) и готовые жанровые пресеты.
- **🗂️ Модульная Коллекция и Настройки**:
  - **Коллекция** разделена на отдельные окна-подкатегории: *Мне нравится*, *Плейлисты и умные авто-миксы*, *Любимые исполнители*, *Альбомы*, *Скачано оффлайн*, *Файлы на устройстве*, *История*.
  - **Настройки** сгруппированы по разделам: *Музыкальный ДНК*, *Эквалайзер и DSP*, *Оформление и тема*, *Таймер сна*, *Виджеты рабочего стола*, *Источники и API*, *Кэш и память*.
  - Повторное нажатие на иконку активного раздела в нижней панели навигации мгновенно возвращает к начальному экрану раздела.
- **🧩 Виджеты для рабочего стола**: 3 адаптивных виджета (**2×1**, **4×2**, **4×3**) с управлением воспроизведением и синхронной строчкой текста песни.

## 🛠️ Технологический стек

- **Язык и UI**: Kotlin, Jetpack Compose, Material Design 3, Dynamic Color (*Material You*), адаптивная вёрстка.
- **Аудио-ядро**: AndroidX Media3 (`ExoPlayer`, `MediaSessionService`), фоновый сервис с системным медиа-уведомлением, `SimpleCache` (до 512 МБ), аппаратный `AudioEffect` DSP.
- **Хранение данных**: Room Database (плейлисты, лайки, оффлайн-треки, история), Jetpack DataStore Preferences (профиль ДНК, настройки волны, кэш обложек авторов).
- **Сетевые источники**: параллельный мульти-репозиторий (`YouTube Piped / Invidious`, `Jamendo HD`, `Audius`, `Deezer`, `iTunes`, `Internet Archive`, `Radio Browser`, `LRCLIB`, `Wikipedia API`).

## 📲 Установка APK

1. Перейдите в раздел **[Releases](../../releases)** или во вкладку **[Actions → Build SlantMuz APK](../../actions/workflows/build-release.yml)** этого репозитория.
2. Скачайте файл **`SlantMuz-release.apk`** на свой Android-смартфон (Android 7.0 и новее).
3. Откройте скачанный файл и подтвердите установку.

---

## 🚀 Автосборка APK в GitHub

В репозитории настроен автоматический пайплайн `.github/workflows/build-release.yml`:
- **При каждом обновлении кода** во вкладке **Actions** автоматически собираются подписанные файлы `SlantMuz-release.apk` и `SlantMuz-debug.apk`.
- **Чтобы выпустить новый релиз вручную**: откройте вкладку **Actions** → **Build SlantMuz APK** → нажмите **Run workflow** (при желании отметьте галочку *«Опубликовать GitHub Release с APK»*).
