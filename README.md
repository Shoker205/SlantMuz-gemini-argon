# 🎵 SlantMuz

**SlantMuz** (от *SlantTech*) — минималистичный аудиоплеер и мульти-источниковый стриминговый хаб для Android в эстетике **Pastel Liquid Glass + Material Design 3**. Слушайте музыку онлайн из открытых каталогов, включайте живые радиостанции со всего мира и воспроизводите треки с памяти устройства — без подписок, рекламы и обязательной регистрации.

---

## ✨ Главные возможности

- **🌐 Мульти-поиск и стриминг**: одновременный поиск музыки сразу по нескольким открытым источникам (*YouTube Music / Piped, Jamendo HD, Audius, Deezer, iTunes, Internet Archive*) с умной склейкой дубликатов и автопереключением при сбое потока.
- **📻 Онлайн-радио**: тысячи живых радиостанций со всего мира (*Radio Browser*) по жанрам и настроению.
- **🎤 Синхронное караоке (LRC)**: живой текст песни (*LRCLIB*) с подсветкой текущей строчки и перемоткой трека по нажатию на любую фразу.
- **🎛️ 5-полосный эквалайзер и эффекты**: встроенный DSP-эквалайзер, усиление баса (*BassBoost*), объёмный звук (*Virtualizer*), увеличение громкости и готовые пресеты.
- **📥 Оффлайн-режим и свои файлы**: скачивание треков в память приложения для прослушивания без интернета, а также удобный сканер локальных аудиофайлов на телефоне.
- **🧩 Виджеты для рабочего стола**: 3 стильных пастельных виджета разных размеров (**2×1**, **4×2**, **4×3**) с управлением плеером и строчкой караоке прямо на домашнем экране.
- **🌙 Темы и таймер сна**: тёмное матовое и светлое жемчужное оформление, поддержка адаптивных цветов *Material You* (Android 12+) и таймер автоотключения музыки.

## 📲 Установка APK

1. Перейдите в раздел **[Releases](../../releases)** или во вкладку **[Actions → Build SlantMuz APK](../../actions/workflows/build-release.yml)** этого репозитория.
2. Скачайте файл **`SlantMuz-release.apk`** на свой Android-смартфон (Android 7.0 и новее).
3. Откройте скачанный файл и подтвердите установку.

---

## 🚀 Автосборка APK в GitHub

В репозитории уже настроен автоматический сборщик `.github/workflows/build-release.yml`:
- **При каждом обновлении кода** во вкладке **Actions** автоматически собираются готовые файлы `SlantMuz-release.apk` и `SlantMuz-debug.apk`.
- **Чтобы выпустить новый релиз вручную**: откройте вкладку **Actions** → **Build SlantMuz APK** → нажмите **Run workflow** (при желании отметьте галочку *«Опубликовать GitHub Release с APK»*).
